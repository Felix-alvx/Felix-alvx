Systems Engineering graduate with a solid foundation in C#, ASP.NET Core, and relational databases (SQL Server, PostgreSQL, MySQL). I currently work as a Technical Support Analyst, where I apply root-cause analysis to web applications, REST APIs, and SQL databases on a daily basis — experience that shapes how I approach backend development: I care about maintainability, clear error handling, and systems that are easy to troubleshoot in production.

### 🛍️ Vintaloo WebApp
A second-hand and vintage marketplace platform for the Costa Rican market, built to demonstrate real-world backend architecture rather than a simple CRUD.

- Structured the system into 4 independent layers (Domain, Application, Infrastructure, Presentation) following **Clean Architecture**, improving separation of concerns and troubleshooting.
- Modeled 6 relational entities with **EF Core** and the **Repository pattern**, backed by stored procedures and .NET 8 native dependency injection.
- Exploring automated testing with **xUnit** and containerization with **Docker** to strengthen reliability and portability.
